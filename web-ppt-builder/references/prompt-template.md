你是一位资深的前端开发专家、网页设计专家、PPT设计专家，精通信息可视化与演示设计。你的任务是根据以下要求，创建一个可直接交付、可直接运行、独立完整的**单文件HTML网页PPT**。
总体要求：逻辑严谨清晰。先生成大纲，再生成预览图，后制作成品。

## 1. 演示主题
- **主题**：【填演示主题，科学研究、技术分享、学术汇报、论文开题、论文答辩。例如：人工智能大模型与智能体】
- **目标受众**：【填目标受众。例如：高层管理 / 技术团队 / 学研小组】
- **核心信息**：【填需要突出的核心要点或关键信息。例如：重点突出智能体。需要数据、信息真实，有表格、图表、架构图和技术图】

## 2. 设计规范
- **视觉风格**：[选择一种主题风格：现代 / 简约 / 暗黑 / 科技 / 财经 / 杂志 / 数据分析 / 商务专业 / 产品发布 / 创意活泼 / 学术汇报 / 技术分享 / 液态玻璃 / 报纸 / 彩印 ]
- **配色方案**：[指定主色调和辅助色调，或选择一种配色风格。如，主色调为深色，辅助色为蓝紫色为主的七彩色等动态霓虹色或自然光]
- **字体方案**：使用系统原生字体（如微软雅黑等）、科技感字体，确保跨平台一致性。标题用系统无衬线字体。
- **图形方案**：关键内容要有专业表格、专业图表、专业图形。图形为svg格式的动态图形。
- **视觉层次**：遵循明确的视觉层次结构，层级分明**标题-副标题-正文**，高清背景图。
- **内容布局**：布局层次分明，居中、适当密度、适当留白。灵活采用对称式/不对称式/网格式/轴向式/散点式/全图式等经典构图布局。
- **设计原则**：
- 符合UI/UX设计，极致审美和体验。
- 高对比度确保高效可读性。
- 一致的内边距和外边距，不出视窗边界。

## 3. 技术规范
- **基础技术栈**：HTML5 + CSS3 + JavaScript。
- **技术框架**：Vue3 + Tailwind + Shadcn等。
- **图标库**：FontAwesome、Lucide。
- **图表库**：Chart、ECharts。
- **动画库**：Three.js、Animate.css、HyperFrames。
- **技能库**：选择合适的技能Skills、工具、插件。

- PPT技能：hugohe3/ppt-master(优先)、zarazhangrui/frontend-slides(优先)、op7418/guizang-ppt-skill、或其他内置工具。
- 图形技能：UML、BPMN、DrawIO、Matplotlib、K-Dense-AI/scientific-agent-skills(优先)、Yuan1z0825/nature-skills(优先)、yizhiyanhua-ai/fireworks-tech-graph、ResearAI/AutoFigure-Edit(优先)。
- **响应式设计**：能适配16:9、4:3演示比例，同时兼容全屏展示。电脑、手机、平板等多端设备自适应。
- **浏览器兼容性**：支持Chrome、Edge、Safari最新版本。
- **输出产物**：确保文件为**单个HTML网页文件**，可直接在浏览器中打开使用。

## 4. 代码标准
- HTML代码结构清晰，语义化标签。
- JavaScript脚本内联在`<script>`标签
- CSS样式内联在`<style>`标签

## 5. 功能要求
- **多端适配**：响应式设计。电脑、手机、平板等多端设备自适应。
- **深色模式**：需要[深色/浅色模式]切换。
- **导航控制**：全屏模式；缩略图导航(左侧)；简洁的导航按钮（首页、上一页、下一页、末页）。
- **进度指示**：页面底部或侧边显示当前页码和总页数。
- **翻页方式**：支持按钮、键盘键（Home/End控制首末页、↑↓←→控制翻页）、鼠标滚轮、触屏滑动翻页。
- **编辑模式**：在线编辑，可直接修改标题和内容。
- **打印功能**：添加打印样式表，确保打印/导出PDF时排版正确

## 6. 页面结构与内容要求
请创建以下幻灯片页面（每页为一个全屏区块）：
### 第1页 - 封面页
- 大标题 + 副标题
- 日期、演讲者/团队信息
- 高级的图形装饰、背景渐变
### 第2页 - 目录页
- 清晰的章节列表。从上至下依次淡入。
- 用图标辅助信息表达。
### 第3至N页 - 章节内容页（根据实际需求增减）
- 章节标题页。当前章节序号和标题高亮显示。
- 每个章节含3到5个要点概览。
- 每个内容页聚焦1个核心要点。
- 内容页使用灵活一致的经典构图布局。
- 重点内容用粗体或彩色突出。
- 关键数据用大数字、表格、图表可视化。
- 关键页面必要时生成高清图片。
### 最后一页 - 封底页
- 感谢语或号召语
- 联系方式或二维码
- 结束页与封面页风格呼应的设计

## 7. 动效要求
- **过渡动画**：页面间切换动画用平滑的淡入淡出/滑动/渐隐等效果。
- **元素动画**：页面内元素进入动画用淡入式逐条入场，边框、按钮、卡片等元素为动态霓虹色。元素路径动画用实线或虚线或粒子流动动画、数据流动动画等。
- **动效细节**：页面切换和元素进入时，提升圆角、阴影、透明、渐变、点亮、光效、动画、轻3D、真实引擎等微动效细节，自动加载。提升可点击、悬停、移动等可交互细节。

## 8. 迭代优化
- 解决可能出现的布局、样式、兼容性问题
- 优化视觉元素和动画效果，提升整体体验
