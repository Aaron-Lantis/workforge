# Layout Catalog (L01–L20)

Twenty classic slide layouts. Pick by the role + content density. Do NOT invent new layouts when one of these fits.

## Quick selector

| Content needs                                    | Use         |
|--------------------------------------------------|-------------|
| Cover page                                       | L01         |
| Title-only page                                  | L02         |
| Section break (chapter divider)                  | L03         |
| Single key statement, big quote                  | L04         |
| Concept + visual side-by-side (50/50)            | L05         |
| Concept + visual side-by-side (60/40)            | L06         |
| Three pillars / features                         | L07         |
| Two-option comparison                            | L08         |
| Four-pillar / quadrant                           | L09         |
| Row of big numbers (KPI strip)                   | L10         |
| One massive statistic / figure                   | L11         |
| Pull quote / testimonial                         | L12         |
| Process flow (3–4 steps)                         | L13         |
| Process flow (5+ steps, timeline)                | L14         |
| 2×2 matrix (e.g. SWOT, prioritization)           | L15         |
| Data table                                       | L16         |
| Horizontal timeline                              | L17         |
| Roadmap / phased plan                            | L18         |
| Agenda / TOC list                                | L19         |
| Closing / thank you                              | L20         |

## Per-layout sketches

> `[#]` = title · `[B]` = body · `[I]` = image/visual · `[C]` = chart · `[N]` = number

### L01 — CenterStack (Cover)
```
+----------------------------------------+
|              [decorative motif]         |
|                                          |
|                  [#]                     |
|               subtitle                   |
|                                          |
|     date · speaker · team               |
+----------------------------------------+
```
Use: cover. Keep title ≤ 24 chars in CN / 8 words EN.

### L02 — CenterTitle
```
+----------------------------------------+
|                                          |
|                  [#]                     |
|            one-line subtitle             |
|                                          |
+----------------------------------------+
```
Use: chapter opener between section break and content.

### L03 — Center (Section Break)
```
+----------------------------------------+
|                                          |
|         Chapter 02                       |
|             [big title]                  |
|         one-line tagline                 |
|                                          |
+----------------------------------------+
```
Use: divider. Darker color treatment. Animated number counter.

### L04 — Center (Key Statement)
```
+----------------------------------------+
|                                          |
|       "A single bold sentence"          |
|         — attribution / source          |
|                                          |
+----------------------------------------+
```
Use: 1-page summary, parting thought, mantra.

### L05 — 2col 50/50
```
+----------------------------------------+
|  [#]                                     |
|  +----------------+----------------+   |
|  | [B]            | [I]/[C]       |   |
|  | bullet list    | chart or img  |   |
|  +----------------+----------------+   |
+----------------------------------------+

### L07 — 3col
```

|  [#]                                     |

```

+----------------------------------------+

|  +-----------+-----------+              |
|  | top-L     | top-R     |              |

### L20 — CenterStack (Closing)
```

Use: closing. Mirror cover's color/motif.

---

## Pacing rules

- L01 → L02 → L05/L07 cluster of 3–5 → L03 (section break) → repeat → L20
- Never two L03 in a row
- Pure-text L04/L12/L19 should be rare (≤ 10% of deck)
- Aim for ~30% of slides to carry a chart or image
- The closing (L20) must echo the cover (L01) — same motif, same color treatment
